# Student Manager 📚

Una aplicación web moderna para la gestión de apuntes académicos, diseñada para ayudar a estudiantes a organizar su horario y material de estudio de manera eficiente.

![Estado](https://img.shields.io/badge/Estado-En%20Desarrollo-yellow)
![Versión](https://img.shields.io/badge/Versión-1.0.0-blue)
![Licencia](https://img.shields.io/badge/Licencia-ISC-green)

## 🚀 Características Actuales

### 📅 Gestión de Horarios
- Visualización intuitiva del horario semanal
- Soporte para clases de múltiple duración (1-3 horas)
- Interfaz adaptable para escritorio y móvil
- Sistema de bloques horarios flexible
- Detección automática de conflictos de horario

### 📝 Gestión de Apuntes
- Creación de apuntes con texto enriquecido
- Soporte para archivos multimedia:
  - 📸 Imágenes (almacenamiento en Cloudinary)
  - 🎤 Grabaciones de audio (almacenamiento en AWS S3)
- Organización automática por materia y fecha
- Búsqueda rápida de apuntes

### 🎨 Interfaz de Usuario
- Diseño moderno y responsivo con Tailwind CSS
- Modo oscuro automático
- Animaciones y transiciones suaves
- Interfaz intuitiva y fácil de usar

## 🛠️ Tecnologías Utilizadas

- **Frontend:**
  - HTML5
  - CSS3 (Tailwind CSS)
  - JavaScript (Vanilla)
  - Firebase Client SDK

- **Backend:**
  - Node.js
  - Express.js
  - Firebase Cloud Firestore

- **Almacenamiento:**
  - AWS S3 (archivos de audio)
  - Cloudinary (imágenes)

- **Despliegue:**
  - Vercel

## 🚀 Instalación y Uso

1. Clona el repositorio:
\`\`\`bash
git clone https://github.com/Brayan-chan/studentManager.git
\`\`\`

2. Instala las dependencias:
\`\`\`bash
cd studentManager
npm install
\`\`\`

3. Configura las variables de entorno:
   - Crea un archivo \`.env\` en la raíz del proyecto
   - Añade las credenciales necesarias para AWS y Cloudinary

4. Inicia el servidor de desarrollo:
\`\`\`bash
npm run dev
\`\`\`
